**Line:** "A guest will call you plastic; you will unfurl one leaf on this sill, and your keeper will never let them forget it."

The fortune is told to the plant on the windowsill, and it promises that plant a small, quiet vindication in front of a skeptical visitor.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.

The program is deterministic and offline: the fortune is one string constant, written with no trailing newline, to `/output/entry.txt` or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
